BlastBox Chat - Privacy Policy

BlastBox Chat is a personal desktop application for displaying YouTube livestream chat in OBS Studio.

Information accessed

With the user's authorization, BlastBox Chat accesses YouTube account information, livestream information, and live chat messages using the YouTube Data API.

Chat information may include participant display names, channel identifiers, message content, timestamps, and publicly available channel profile information.

How information is used

YouTube information is used to identify the authorized user's livestream, display chat messages in OBS Studio, and maintain a private participant list for the streamer.

Chat messages displayed in the OBS overlay may be visible to viewers of the livestream.

Local storage

BlastBox Chat stores application settings and a participant list locally on the user's computer. The participant list may contain channel identifiers, display names, message counts, and timestamps.

Google authorization credentials are stored locally using operating-system credential protection.

Data sharing

BlastBox Chat does not operate a separate cloud database for collecting livestream chat information. Chat content is displayed through the streamer's configured OBS output.

Data deletion and access revocation

The user can clear the participant list within the application and revoke the application's Google account access through Google Account settings.

Locally stored application data can also be removed by the user from their computer.
