BlastBox Chat

BlastBox Chat is a personal Windows desktop application for displaying YouTube livestream chat in OBS Studio.

What does it do?

The application connects to the user's YouTube account with permission, automatically discovers their livestream, and displays live chat messages through a customizable OBS Browser Source.

It also maintains a private, locally stored list of chat participants for the streamer to reference.

Why does it request YouTube access?

BlastBox Chat requests read-only YouTube access to identify the authorized user's livestream and retrieve its live chat messages.

The application does not require permission to upload, modify, or delete YouTube videos.
